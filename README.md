# Список дел

Небольшой учебный проект: страница, где можно добавлять дела, отмечать выполненные и удалять их.

## Как открыть

Откройте файл `index.html` в браузере. Установка программ не нужна.

## Учебный маршрут по Git

1. Посмотрите файлы проекта и решите, что хотите изменить.
2. Внесите небольшую правку, например поменяйте текст заголовка.
3. Посмотрите изменения командой `git status`.
4. Посмотрите подробности командой `git diff`.
5. Подготовьте выбранные изменения командой `git add index.html`.
6. Сохраните их в истории командой `git commit -m "Изменил заголовок"`.
7. Создайте репозиторий на GitHub и свяжите его с папкой проекта.
8. Отправьте сохранённую историю командой `git push`.

Коммит — это именованный снимок изменений. Git сохраняет снимки локально; GitHub хранит удалённую копию и помогает делиться проектом.

## Идеи для следующих изменений

- Изменить заголовок и описание.
- Добавить кнопку очистки списка.
- Сохранять дела после перезагрузки страницы.
- Создать отдельную ветку и изменить цвет кнопки.
